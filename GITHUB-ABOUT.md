## Texto para a apresentação do README

A **AC Transporte** é uma plataforma institucional para operações de transporte rodoviário de cargas em São Paulo e região. O projeto reúne informações sobre a empresa, serviços, frota e canais de atendimento em uma experiência responsiva, com animações de scroll, transições entre páginas e chamada direta para cotação.

A aplicação também conta com formulário de cotação integrado à API, rastreamento público por código e painel operacional com autenticação e controle de status.
